# Flowers for Beee

A living bouquet drawn entirely with animated binary characters.

## View the website

The public site will be available at:

<https://archellearon-dev.github.io/flowers-for-beee/>

GitHub Pages may take a few minutes to publish after it is enabled.

## Run locally

From the project directory, start a local server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/> in your browser.
